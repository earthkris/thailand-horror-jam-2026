5. Using the 64×64 Tiles

The main environment tiles included in this package use a 64×64 pixel resolution.

The tiles can be used with Unity's Grid and Tilemap systems or placed manually depending on the requirements of your project.

For the best pixel art appearance:

Use Point (no filter) texture filtering where appropriate.
Avoid texture compression settings that reduce pixel clarity.
Keep consistent Pixels Per Unit settings across related sprites.
Use Unity's Grid and Tilemap tools for precise tile placement.
Consider using a Pixel Perfect Camera if your project requires pixel-perfect rendering.
Avoid unnecessary scaling that can distort the original pixel art.

The assets are designed to be modular, allowing different tiles and environment elements to be combined to create custom level layouts.

6. Particle Effect

The package includes a Particle System used in the Demo Scene.

The Particle System is saved as a Prefab and can be found inside:

Prefabs/Particles

To use the effect in another scene:

Open the Prefabs/Particles folder.
Select the Particle System Prefab.
Drag it into your Scene.
Position it where required.
Adjust the standard Unity Particle System settings if customization is needed.

The included particle effect can be modified to better match the visual style and requirements of your project.
